## Interpretation and limits

Setup failures are recorded separately and are not product passes. The C4 baseline
uses an independently created repository with identical payloads and deterministic
Git commit metadata; Git LFS pointer OIDs are content-derived. C3 uses a disposable
local bare Git remote plus a loopback-only local Git LFS batch/download endpoint.

establish behavior for other Git attribute sources, external LFS servers, or other
revision-switch workflows.
